# 🔐 CryptChat – Secure Messaging App

## 📌 Overview
CryptChat is a secure messaging web application that allows users to send encrypted messages.

---

## 🚀 Features
✔ User login/signup  
✔ Encrypted messaging  
✔ Secure database storage  
✔ Password reset  
✔ Chat history  

---

## 🛠 Tech Stack
- PHP
- MySQL
- JavaScript
- HTML/CSS

---

## 📂 Project Structure
auth/ → Authentication  
chat/ → Messaging system  
config/ → Database config  
assets/ → Media files  

---

## ▶️ How to Run
1. Setup XAMPP  
2. Import database  
3. Configure db_connection.php  
4. Run on localhost
